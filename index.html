🤖 AI Setup Guide (Click to Expand)

This toolkit uses Google's Gemini AI. It is free to use, but you need to get your own "Key" from Google.

Step 1: Get a Key

Go to Google AI Studio and click Create API Key.

Step 2: Create Project

If asked, select "Create API key in a new project". Give it a name like "DM Tool".

Step 3: Copy & Save

Copy the long code starting with AIza....

Go to the Prep Tab, paste it into the "AI Configuration" box, and click Save.

📝 Notes & Formatting Guide

You can use special syntax in your notes to format text and create clickable dice rolls.

Feature Syntax to Type Result
Bold **Bold Text** Bold Text
Italics *Italic Text* Italic Text
Headers # Main Header
## Sub Header		 Large, bold headings
Links [Google](https://google.com) Google (Clickable)
Dice Roller [[1d20]]
[[1d8+3]]
[[2d6+1d4+2]] 		Creates a clickable button that rolls the dice in the chat.

💡 Pro Tips:

  • Lists: Use - or * at the start of a line to create bullet points.
  • Math in Dice: You can add modifiers directly inside the brackets (e.g., [[1d20+5]]).
  • Organization: Use Headers (#) to separate different sections of your session notes for easy scanning.
                   

                        ⚠️ Getting a "Quota Exceeded" Error?                    

                                       
                        Error: { "code": 429, "status": "RESOURCE_EXHAUSTED" ... }                    
                   

                        This error means you have hit the daily limit for the Free Tier AI usage, or the key has expired.                    

                   
                       

✅ The Fix:

                       

                            Simply create a new API Key and paste it into the Prep Tab. New keys reset your daily usage limit.
